# APS_2026
# O diagrama de casos de uso do BiblioTech mostra as principais funcionalidades do sistema e os atores que interagem com elas. Foram utilizados os relacionamentos «include» para representar ações obrigatórias, como identificar o leitor antes de emprestar, reservar ou bloquear, «extend» para indicar uma ação opcional durante a consulta ao acervo, e a generalização para mostrar que Leitor e Bibliotecário são tipos de Usuário. Isso torna o diagrama mais organizado e evita a repetição de funcionalidades.
